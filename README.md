## Projects

**[juice-shop-pentest](https://github.com/Sabirin1662/juice-shop-pentest):** A full web application penetration test of OWASP Juice Shop, documented as a client-style report. Five findings across five vulnerability classes (SQL injection, broken access control, reflected XSS, sensitive data exposure, missing brute-force protection), each with severity ratings, CVSS scores, reproduction steps, evidence and remediation advice.

**[header-tls-check](https://github.com/Sabirin1662/header-tls-check):** A Python command-line tool that checks a website's security posture: security headers, cookie flags (Secure, HttpOnly, SameSite) and TLS configuration. It automates the manual checks a tester runs by hand during a web assessment.
